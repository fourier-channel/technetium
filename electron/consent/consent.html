QuickQueue

Send images to Technetium straight from Windows.

This will put an Icon and a Menu Option on your operating system's right-click context menu. It will also, separately, set the custom keybind qq.

If you opt out of these features now, you can always enable them later — QuickQueue › Integration settings.

Adds “Queue in Technetium”, with the Technetium icon, when you right-click an image. On Windows 11 it appears under “Show more options”. Nothing else on the menu changes, and removing it removes it completely.
Claims the shortcut system-wide, so it works while other applications are focused. Independent of the context menu — you can have either, both, or neither.
